# Changelog

DramaForge 的用户可见变更记录，按版本列出新增功能、体验改进和问题修复。

写作约定：只写用户能感知的结果，每条一到两句；合并重复内容，保留影响使用的限制。接口、代码、测试和评审过程留在工程文档与 PR 中。未发布内容记入 `Unreleased`，按 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 分组。

## [Unreleased]

### Added

- 图片节点选中后顶部工具条可用：预览大图与按当前显示版本下载（未入库的本地/预设图下载置灰）。
- 图片节点「替换素材」真实可用：本地上传入库并经交付校验后钉版替换（刷新可恢复、可作下游参考图，上传失败/校验未过/节点已删均保留原图）；也可从生成历史中挑选图片素材替换。分镜与资产组成员不提供单卡替换。
- 图片节点新增「旋转与镜像」内联编辑：工具条直接进入编辑态，四角手柄拖转任意角度（Shift 吸附 15°）或输入角度，支持水平/垂直镜像，结果另存为新的图片节点（原图保留，刷新可恢复、可作下游参考图）。
- 图片节点新增「裁剪图片」：自由/固定比例裁剪 + 90° 步进旋转，弹窗中预览、重置，结果另存为新的图片节点；GIF 与 SVG/预设图不支持像素编辑，入口按原因禁用。
- 图片节点新增「宫格切分」：2×2–5×5 预设与自定义行列（每维 1–5、至多 25 块），弹窗预览切线后逐块上传入库并作为普通图片编组落位（行优先命名）；逐块显示进度、失败只重试失败块，刷新后可对账补做未完成块，不重复上传已成功块或重复建节点。
- 图片节点连到视频节点即首帧图生视频：首个就绪图片引用自动成为首帧素材，composer 标注「首帧：…」，其余图片引用不参与本次生成；所选模型不支持首帧模式时提示换模型，不静默切换。分镜图组/资产组成员卡也可作首帧来源（成员镜头选定图/候选参考图经统一解析作输入），成员分属不同分镜组时按各自分镜正确解析。视频/音频等非图片素材上游如实拦截（参考/编辑/延长模式后续开放）。

### Changed

- 视频生成契约同步 Seedance 2.0 系列与 Wan 3.0 Prime 扩展模式：模型目录可声明各模型支持的首帧/首尾帧/参考/编辑/延长模式，视频素材（首帧图、参考图/视频/音频）可按角色随任务与积分预估提交；画布侧的模式选择与素材拾取入口随后续版本开放。
- 图片、视频节点未实现功能的「即将上线」占位入口整体下线：图片顶部工具条的生成/编辑菜单、两类节点空态的占位入口、composer 内的参考/标记/风格/特效/角色库/运镜占位菜单、预设模板、随机灵感、翻译与高级参数占位按钮均不再显示；保留真实可用的参数、引用与生成操作。

## [1.5.0] - 2026-10-22

### Added

- 制作图片可以选择生图模型：画布图片节点与分镜批量生图都能挑选模型和尺寸，提交前显示预计消耗的积分；尺寸可选项与参考图上限随所选模型变化。旧草稿保存的模型若已下线，会提示重新选择后才能提交。
- 首页开场改为两条宣传片轮播：短片播完自动切换下一条，播放/暂停按钮可直接控制；影片加载失败时停在静态画面。

### Changed

- 积分入口统一命名为「我的积分」，积分相关页面与提示中的「公司」统一改称「组织」。

### Fixed

- 手机端首页剧集展播的翻页按钮现在会带动胶片卡横向滑动；滑到首尾时无缝接续，不再长途倒滚。

## [1.4.1] - 2026-10-20

### Fixed

- 修复纯文生视频选择生成模型后仍按默认模型生成的问题：所选模型现在会随请求提交并生效。

## [1.4.0] - 2026-10-20

### Added

- 视频节点可直接播放成片：生成完成后节点上即为播放器，悬浮工具条提供下载、放大播放与截取画面入库为图片节点；右键菜单可将当前画面保存进资产库。
- 视频生成支持选择模型：可统一为项目或逐镜调整生成模型与参数，提交前显示预估积分消耗；模型不可用时会在参数区明确提示并拦截提交。

### Changed

- 取消生成需二次确认，确认后节点恢复生成前的画面并解除任务绑定——再次生成为全新任务，不再沿用已取消任务的参数；打开旧画布也能找回取消前的画面。
- 重新生成进行中原画面以毛玻璃垫底并显示进度，节点尺寸不再跳变，也不再闪回空白状态。
- 放大播放沿用画布播放器的进度、音量与暂停位置，窗口按视口高度限宽。
- 视频节点不再允许向下游连接图片节点（图片仍可作为上游连接视频）。

### Fixed

- 修复取消或重新生成后，下载与右键保存可能指向未显示版本的问题：两者现在始终对准正在显示的画面，无法确认时入口禁用。
- 取消生成后服务端完成积分结算时，页面余额现在会正确刷新。

## [1.3.0] - 2026-10-19

### Added

- 积分购买闭环上线：积分页可查看余额与交易流水，选购一次性积分包并通过支付宝完成支付；生成提交时积分不足会引导前往购买。
- 新增组织管理端（dramaforge.video/org/）：组织可使用自有账号注册与登录，管理组织与成员，并在资金中心分配与回收成员额度、处理对账。
- 注册与登录拆分为独立弹窗，注册改用邮箱自有账号，并支持「忘记密码」找回。
- 邮件落地页上线：注册验证、重置密码、接受邀请的链接打开后可就地完成操作，令牌不会留在地址栏；验证或重置链接失效、登录提示邮箱未验证时，页面可重新发送验证/重置邮件；支付宝统一返回页按订单状态显示到账、处理中或已关闭结果。

### Changed

- 错误提示不再显示问题编号，保留易懂的失败原因与处理指引。

### Fixed

- 生成任务已结束但后台仍在结算/对账时，节点与任务列表不再错误停留「生成中」转圈：失败、取消和成功结果立即显示，「重新生成」在服务端确认可重试前保持禁用并提示原因。
- 脚本生成器断开上游连线后恢复三入口状态：尚未生成分镜的节点重新显示「剧本生成分镜脚本 / 角色生成分镜脚本 / 自己编写分镜脚本」入口，不再停留在提示占位；已生成分镜的节点保持不变。

## [1.2.0] - 2026-10-15

### Added

- 新增帮助中心（dramaforge.video/help/），提供从剧本生成、分镜和参考素材准备到图片与视频制作的图文入门教程，并可查阅项目与画布管理、剧本编写、素材上传、独立节点、剪辑导出与任务恢复等操作指南。
- 视频节点支持纯文生视频：无需连线即可填写提示词生成，并可调整生成时长（4–30 秒）、画面比例、分辨率与配音开关；脚本生成器无上游时也可仅按剧情描述生成分镜。

### Changed

- 「角色生成分镜脚本」入口现在同时连入剧本文本与角色节点：分镜生成需要恰好一个剧本版本，角色作为附带引用，避免生成请求必被服务端拒绝。
- 仅有素材/参考图而没有剧本或分镜上游时，视频与脚本生成器的提交会被阻止并说明原因，不再发出必然失败的生成请求。

### Fixed

- 打开或刷新页面时不再出现白色闪屏，启动与登录中转过程统一为深色品牌加载画面。

## [1.1.0] - 2026-10-14

### Added

- 项目详情可查看生成的剧本、按场景编辑并保存新版本，再将选定剧本放入画布继续制作；重新生成保留旧方案。
- 生成剧本时可点击「试一试」轮换五条故事创意示例，填入后仍可自由修改。
- 项目剧本支持七色标签，便于区分不同故事方案；标签保存在当前浏览器，按生成版本分别标记。

### Changed

- 项目卡片支持自定义封面：菜单「修改封面」直接打开系统文件选择，上传后自动设为封面；已设置的项目可「恢复默认封面」。无封面时卡片显示统一的图片占位视觉。
- OPC 首页整体改版为影院式落地页：首屏以真实展播作品铺满画面，配大标题与主行动按钮；展播区改为胶片条式三联画幅；匿名访客可浏览展播、在受限操作处唤起登录，已登录用户可从首屏继续最近项目；窄屏下导航为底部悬浮条。首页不再内置搜索框，项目检索仍在项目中心进行。
- 全站品牌视觉更新：更换为新版 Logo，主色由青色系调整为与新标识同源的紫罗兰，按钮、焦点描边、选中态等随之更新；界面语义色（成功、警示、错误）保持不变。
- 修改已有分镜前展示对生成媒体和剪辑的影响；剪辑台可查看差异，按需合并镜头或更换素材。

- 生成参数仅提供当前支持的选项；批量生成可保留各镜头原配置，也可明确改回默认档位。

### Fixed

- 项目剧本按生成版本逐张展示：多次生成保留全部候选卡片并标记「当前版本 / 候选版本」，不再只显示最近一张。
- 「开始生成」点击后立即禁用并显示加载图标，创意保存与任务提交全程防重复点击。
- 从项目详情放入画布的剧本可直接阅读正文、查看或编辑，并连接脚本生成器；编辑保留原有场景和对白。
- 项目封面回退图片的缩略图暂未就绪时自动尝试刷新；更换回退素材后，图片加载失败可重新自动恢复。

- 修复项目编辑和生成入口被错误关闭的问题；项目访问权限失效、退出或切换空间后，旧操作不会继续提交。

- 刷新或重新进入项目后继续跟踪未完成的生成任务，避免进度丢失和旧状态回退。

## [1.0.0] - 2026-10-11

### Added

- 可浏览、预览和使用同 OPC 同事的共享素材，也可另存到自己的未归档项目；原素材保持只读。
- 剪辑台配乐可静音或恢复声音，支持撤销和保存，导出成片时同样生效。

### Changed

- 批量生成或重做视频后，自动采纳并确认本批次的新结果；手动改选优先，失败时保留原视频。单镜手动重做仍由用户采纳。
- 分镜图就绪后自动准备视频运动提示词；画布镜头卡可直接切换候选图，已确认的镜头也可继续重做。
- 剪辑台新增时间轴缩放滑块，拖动即可连续放大或缩小。
- 剪辑台加载时显示当前步骤，便于区分加载数据、生成粗剪和准备内容。
- 删除字幕后可撤销恢复，保存后仍可恢复历史字幕；保留当前配乐，恢复的字幕需重新确认。
- 变更记录统一改为简短的使用效果说明。

### Fixed

- 字幕保存遇到网络中断后，刷新仍可继续；保存期间的新编辑和冲突时的草稿会保留。
- 配乐预览跟随视频播放、暂停、定位和倍速变化，音量与淡入淡出设置正确生效；修改字幕后不再丢失配乐选择和确认状态。
- 字幕对齐进度持续更新，并显示排队、就绪和失败情况，避免已完成后仍提示无字幕可处理。
- 配乐轨清楚区分尚未配乐、生成中、失败和待确认，未确认的配乐不再显示为可用片段。
- 拖动片段靠近时间轴边缘时自动滚动，时间零点与轨道面板左边缘对齐。
- 编组工具条不再被相邻镜头卡遮挡，缩放或拖动后仍可点击。
- 素材入库前明确确认目标项目；失败重试不再重复创建副本，批量入库保留未完成项供重试。
- 分镜图和视频生成失败或取消后可按提示恢复；结果尚未确认时只能继续查询原任务，避免重复生成。
- 批量生成未受理的镜头会显示原因，取消请求也会等待实际取消完成后再更新状态。
- 任务进度和最终结果持续同步，避免进度达到 100% 后仍看不到产物；刷新恢复任务时不再因旧状态崩溃。
- 整组生成与选定操作减少相互冲突，执行失败会明确提示；状态已变化的镜头会跳过，不再打断整批确认。
- 分镜图补齐后继续推进视频准备；准备失败时提供手动重试入口，重新打开画布也可恢复推进。
- 较早任务迟到的结果不再覆盖较新的选择；退出或切换空间后，旧操作和旧结果不再混入当前会话。
- 素材下载与镜头操作按当前可用状态开放，避免显示无法使用的入口。

### Removed

- 项目详情移除尚未开放的占位页签，保留「概览」和「生成任务」。

## [0.7.0] - 2026-10-05

### Added

- 分镜图生成失败后可单镜重试；图像和视频任务支持按可用操作取消或继续查询，长时间无进展时显示提示，原有媒体继续保留。
- 「开始制作」不可用时显示原因；缺少剧本时可直接前往画布创建，保存后即可继续。

### Changed

- 剪辑台优先加载当前播放位置的画面，减少等待；加载失败时显示重试入口。
- 分割、换条、修剪和缩放时复用已加载的素材与缩略图，减少重复下载和画面重载。
- 刷新或重新打开剪辑台时复用本地素材，减少加载流量；浏览器无法保留素材时仍可正常联网加载。
- 同一素材拆成多个片段后，减少内存占用和重复读取。

### Fixed

- 画布重命名不再引发无谓的保存冲突；确有远端内容变化时仍提示用户选择。
- 修复剪辑台快速换条或撤销后监视器黑屏的问题。

## [0.6.0] - 2026-10-03

### Added

- 操作结果以通知显示，成功、警告和错误均有文字与图标提示；重复通知合并显示。
- 新增可探索的创作流程图，展示从剧本到成片的步骤。

### Changed

- 图片和视频在画布中按原始比例完整显示，尺寸标注更准确。
- 分镜节点优先显示从剧本提取的剧名，减少「文本 1」等默认标题。
- 双击图片或视频节点即可放大并居中查看。
- 已供后续生成使用的图片和视频收起提示词编辑区，图生图迭代仍可继续编辑。
- 参考素材统一显示缩略图、序号和引用标记，支持悬停预览与移除。

### Fixed

- 图片生成期间隐藏「替换素材」，避免中断当前任务。
- 手写内容保存中断后可继续重试，不再反复卡在保存失败。
- 离线清空画布后，云端内容不再直接覆盖本地修改；有冲突时可选择保留本地。
- 画布保存失败后继续编辑并重试，不再持续报错或误报云端冲突。
- 生成提交失败后可按原参数重试，不再因重复提交校验而被拒绝。

## [0.5.0] - 2026-10-02

### Added

- 「我的额度」显示积分余额，并支持分页查看交易流水。
- 剪辑台播放时自动滚动跟随播放头，空格键可播放或暂停，输入文字时不受影响。
- 剪辑预览优先使用轻量素材和预制缩略图，减少等待与下载量。
- 监视器支持拖动画面、等比缩放和双击复位，仅影响预览，不改变导出画面。

### Changed

- 剪辑素材加载异常时自动尝试兼容播放方式，缩略图失败时显示素材封面。
- 画布图片编辑支持 1–10 张参考图，可选 2K 或 4K，每次生成一张；缺少参考图时提示补充。

### Fixed

- 剧本正文可正常保存，空白文本先保留为画布草稿。
- 参数不完整时，快捷键不再触发必然失败的生成提交。
- 画布自动更新名称后不再误报云端内容冲突。
- 时间轴播放头与轴线对齐，起点不再被裁切。
- 竖屏素材的时间轴缩略图不再压扁、发糊。

## [0.4.0] - 2026-10-01

### Changed

- 默认进入新版剪辑台，素材库、监视器、检查器和时间线分区呈现。
- 支持逐帧查看、快进倒放、修剪、分割、拖拽排序、多选、吸附、候选换条和撤销。
- 支持字幕合成、对齐与确认，以及配乐生成、试听和选定；可不配音乐直接导出，已开始配乐选择时需先完成确认。
- 导出前显示检查清单，可选软字幕、烧录字幕或无字幕，并查看渲染历史和下载成片。
- 剪辑内容支持云端保存与本地草稿，保存冲突会明确提示。

## [0.3.0] - 2026-09-30

### Added

### Changed

- 素材列表滚动到底自动加载下一页，日期分组可展开或折叠。
